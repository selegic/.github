We build software that runs natively on Salesforce, and we publish it as open source.

## Products

### [Selegic CPQ](https://github.com/selegic/selegic-cpq-force)

Configure, price and quote (CPQ) that runs inside your Salesforce org: product discovery, bundle
configuration, pricing, quotes, orders, contracts and amendments. It also includes AI agents and
MCP tools, so assistants such as Claude and ChatGPT can work with quotes.

- Fully open source under the Apache License 2.0. There is no paid edition.
- You host it yourself: the Salesforce package works on its own, and you can add the backend
  and AI agent services in your own cloud.

### [Switch to Classic](https://github.com/selegic/switch-to-classic)

A Chrome extension that opens the current Salesforce Lightning page in Salesforce Classic, on
the same record, in one click. MIT licensed.
[Get it from the Chrome Web Store](https://chromewebstore.google.com/detail/selegic-switch-to-classic/ellmmiehdcccalmmdfpoeeablbpnihac).

## Get involved

- **Use it:** each repository's README explains how to install it.
- **Report a bug or ask for a feature:** open an issue in the product's repository.
- **Contribute:** read the repository's `CONTRIBUTING.md` first. AI-assisted contributions are
  welcome when you disclose them and stand behind the result.
- **Report a security problem privately:** follow the repository's `SECURITY.md`. Do not open a
  public issue.
